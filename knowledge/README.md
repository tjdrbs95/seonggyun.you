# 솔루션 자료

제안서 에이전트가 근거로 읽을 Workday 자료를 이 폴더에 넣으세요. `python -m proposal_agent <RFP>` 를 실행하면 자동으로 읽습니다.

- Workday 표준 제안서 / 솔루션 설명문서 (예: `Workday Proposal for 한국 고객_30.09.2026.pdf`)
- 제품 데이터시트, 기능 설명 자료, 과거 RFP 답변(Q&A) 모음
- 형식: PDF, DOCX, PPTX, XLSX, MD, TXT (HWP는 PDF로 변환)

이 폴더의 파일은 `.gitignore` 로 커밋되지 않습니다(이 README만 예외). 저장소가 공개이므로 기밀 자료를 다른 곳에 커밋하지 마세요.
