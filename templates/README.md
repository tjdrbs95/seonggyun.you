# 템플릿

`workday_template.pptx` 이름으로 **Workday Corporate PowerPoint Template** 을 이 폴더에 두세요.
(`Workday Presales` 드라이브 폴더의 `Workday Corporate PowerPoint Template (1).pptx`)

회사 기밀 문서이므로 `.gitignore` 에 의해 커밋되지 않습니다. 다른 템플릿을 쓰려면 `-t 경로` 로 지정하세요.
템플릿의 레이아웃 이름(`Title Slide`, `Title Only`, `1/2_Headline`, `Section Title`, `Bumper Slide`)을 찾아 쓰고,
없으면 비슷한 기본 레이아웃으로 대체합니다.
